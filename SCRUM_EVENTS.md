# Scrum Events — Online Food Ordering App

## Sprint 1 Goal
Allow customers to log in, browse the menu, and add food items to the cart.

## Daily Scrum example
### Student 1
- **What did you complete?** I completed the Login UI.
- **What will you do next?** I will implement login validation.
- **Any blocker?** No blocker.

### Student 2
- **What did you complete?** I created the restaurant page.
- **What will you do next?** I will display the menu.
- **Any blocker?** I need the food-item details.

The Scrum Master records the answers.

## Sprint Review
Demonstrate this increment:
Login → Restaurant Selection → Menu → Food Selection → Add to Cart → View Cart.

## Sprint Retrospective
| Question | Example answer |
|---|---|
| What went well? | Login and menu were completed. |
| What did not go well? | Cart took more time. |
| What did we learn? | Better estimation is needed. |
| What will we improve? | Divide large tasks into smaller tasks. |

## Sprint 2
Work on US04 Online Payment and US05 Order Tracking.

### Online Payment tasks
- Create Checkout Page
- Select Payment Method
- Enter Payment Details
- Process Payment
- Display Payment Status
- Generate Confirmation

### Order Tracking tasks
- Create Tracking Page
- Show Order Confirmed
- Show Preparing
- Show Dispatched
- Show Delivered

Move each task through Todo → In Progress → Testing → Done as the work is actually performed.
